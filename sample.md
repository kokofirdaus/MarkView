# Selamat Datang di MarkView! 🚀

Ini adalah aplikasi **Markdown Viewer & Editor** native Windows yang dibuat dengan **C# 12 · .NET 8 WPF**.

## Fitur Utama

- [x] Zero WebView — 100% native DirectX / GDI+
- [x] Tampilan familiar seperti Notepad / MS Word
- [x] Split View (Editor di kiri, Preview di kanan)
- [x] Live sync rendering dengan debounce 300ms
- [x] Dark Mode dan Light Mode
- [x] Shortcut keyboard lengkap
